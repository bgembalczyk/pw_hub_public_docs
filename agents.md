# PW_hub - Agents Entry Point

Ten plik jest **punktem startowym** dla agentów i developerów.

👉 **Najważniejsze instrukcje są w `agents_instructions/README.md`.**

## Co dalej
1. Otwórz `agents_instructions/README.md` i przeczytaj zasady działania systemu agentowego.
2. Jeśli użytkownik wskazuje konkretną rolę lub creed, wczytaj odpowiedni plik z `agents_instructions/` i dodaj do kontekstu.
3. Jeśli brak wskazania, samodzielnie dobierz odpowiednich agentów oraz creedy.

## Szybkie linki
- System agentowy: `agents_instructions/README.md`
- Role: `agents_instructions/roles/`
- Agenci tech: `agents_instructions/tech/`
- Creedy: `agents_instructions/principles/`
- Szczegółowe standardy: `agents_instructions/base_rules/` (testing, code quality, docs, Django)

> Ten plik ma charakter przekierowania. Szczegółowe zasady są w README systemu agentowego.
